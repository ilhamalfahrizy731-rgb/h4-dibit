## 📌 About The Project

**Ultra Wordlist Engine v4.0** adalah alat generator *wordlist* angka berbasis Python yang dirancang dengan antarmuka **Cyberpunk CLI** berkecepatan tinggi. Script ini mampu memproduksi kombinasi angka acak tanpa batas (*unlimited*) secara *real-time* tanpa adanya duplikasi data.

### ✨ Key Features

- ⚡ **High-Speed Generation** — Menggunakan struktur data `Set` internal Python untuk pemrosesan dan ekstraksi data super cepat.
- 🚫 **Zero Duplicate Guarantee** — Sistem otomatis memfilter dan memberi peringatan warna merah saat angka duplikat terdeteksi.
- 🎯 **Flexible Digit Modes**:
  - **4-Digit Mode** (`0000` - `9999`)
  - **6-Digit Mode** (`000000` - `999999`)
  - **Custom Length Mode** (Bebas menentukan panjang digit misal 8, 10, dll.)
- 💾 **Smart Auto-Save & Recovery** — Fitur simpan otomatis setiap 50 item dan *Graceful Shutdown* (`Ctrl + C`) agar file `wordlist.json` tidak pernah rusak (*corrupt*).
- 🎨 **Ultra-Cyber Terminal UI** — Tampilan modern berbasis ANSI 256-Color, *ASCII Header*, bingkai presisi, dan pelacakan durasi waktu secara *live*.
- 📦 **Zero External Dependencies** — Menggunakan murni modul bawaan Python (*Standard Library*), langsung *run* tanpa perlu `pip install`.
